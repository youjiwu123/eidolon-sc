# 本地定制版说明

这是基于 [Sallyn0225/eidolon-sc](https://github.com/Sallyn0225/eidolon-sc) 的**个人定制版**。
上游的安装、配置、开发约定请看 `README.md`、`AGENTS.md` 和 `docs/`；这份文件只说明「和上游不一样的地方」。**从零部署看 [`docs/deploy-fork.md`](docs/deploy-fork.md)。**

## 相比上游多了什么

**好感度**

- 六档：冷淡 0 / 疏远 20 / 信任 40 / 亲近 65 / 亲密 85 / **爱意 100**，上限 120
- 判断模型按档位放宽：越亲近，能接受的话越多（`affinity_judge.py` 的 `TIER_NOTES`）
- 爱意档的性相关内容算加分；亲密档算轻微不适；亲近及以下仍算越界
- **辱骂、威胁、人身攻击在任何档位都是越界（-6）**
- 亲密/爱意档的人设加了「偶像也是恋人」的一层（`affinity.py` 的 `_TIER_PROMPTS`）

**文字聊天里的动作**

- 用户可以用圆括号写动作：`（走过去抱住她）今天辛苦了`
- 文字回合允许她同样用圆括号写自己的动作；通话里不允许（会被念出来）
- 朗读者（TTS）会跳过括号里的动作

**群聊**（`.scratch/group-chat/spec.md`）

- 一个对话里 2–4 个人，各自用自己的语气说话
- **谁接话由后台模型判断**：点名优先、上轮说过话的往后排、用户说累了可以两人接
- 回复流式逐条出现（SSE），带「某某正在输入……」
- 输入框用 `/名字` 可以只对某个人说
- 群可以改名；「让她们自己聊」是常开开关（每 20 秒一轮）
- **群聊完全不动好感度**，单聊的代码一行没改

**其他**

- 接电话时她先开口：`/api/characters/{id}/call-opener/speech`（合成一次，缓存在 `/data/speech`）
- 主动搭话 + 浏览器通知（`reach_outs`，默认每天 8 次）

## 需要自备、仓库里没有的东西

| 东西 | 为什么没有 | 怎么补 |
|---|---|---|
| `.env` | 含密钥和个人地址 | 复制 `.env.example` 填自己的 |
| `corpus/` | 剧情库与立绘（约 2.8 GB，版权原因） | 自行导入，见 `docs/` |
| `certs/` | TLS 证书和私钥 | 自己生成，见 `docs/deploy.md` |

## 一处需要改的地方

`deploy/https-nginx.conf` 里的 `YOUR-TAILNET-HOSTNAME.ts.net` 是占位符，换成你自己的
Tailscale 域名（或局域网地址），并把证书放进 `certs/`。

## 注意

这份定制是「自己用着舒服」的取向，不是通用方案：

- 好感档位、判定措辞都是本地调过很多轮的，换个部署环境可能需要重新调
- 群聊的选人逻辑依赖后台模型，配置不同表现会不一样
- 上游更新后合并时，`affinity.py`、`affinity_judge.py`、`engine.py`、`app.py` 容易冲突

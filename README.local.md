# 本地定制版：改了上游的哪几项

这是基于 [Sallyn0225/eidolon-sc](https://github.com/Sallyn0225/eidolon-sc) 的**个人定制版**。
上游的安装、配置、开发约定见 `README.md`、`AGENTS.md` 和 `docs/`；这份文件只讲**与上游不同的地方**。

> 从零部署看 [`docs/deploy-fork.md`](docs/deploy-fork.md)。

---

## 一、好感度：六档、上限 120、按档位放宽判定

### 档位

| 档位 | 分数起点 | 她的态度 |
|---|---|---|
| `cold` 冷淡 | 0 | 客气、疏远，话少 |
| `distant` 疏远 | 20 | 还带着距离 |
| `trust` 信任 | 40 | 正常相处 |
| `close` 亲近 | 65 | 会主动关心你 |
| `intimate` 亲密 | 85 | 依赖、撒娇 |
| `love` 爱意 | 100 | 像恋人 |

上限 **120**（上游是 100），每天最多涨 6。

### 判定按档位放宽

同一句话，在不同档位得到的判定不一样——这是本版改得最多的地方：

| 档位 | 能接受的话 | 越界时 |
|---|---|---|
| 冷淡 / 疏远 | 只有日常寒暄 | 轻则不悦 |
| 信任 | 玩笑、关心 | 轻微不适 |
| 亲近 | 暧昧的试探 | 算「过线」但不掉很多 |
| 亲密 | 带有肢体接触意味的话 | 轻微不适（**不再是越界**） |
| 爱意 | 性相关的话算**加分** | 基本不越界 |

**但有一条对所有档位都成立**：辱骂、威胁、人身攻击一律 **-6**，亲近了也不豁免。

### 掉分与恢复

- 越界一次 **-6**（上游是 -10）
- 每档变化步长 `-5 / -2 / 0 / +1 / +2`
- 连着 8 轮不愉快会进冷却（`FED_UP_TURNS=8`）

### 爱意档的人设另写

`affinity.py` 里 `_TIER_PROMPTS` 为亲密/爱意单独加了一层「偶像也是恋人」的设定——不只是语气变软，而是**关系定义变了**。

## 二、文字聊天里的动作描写

### 你可以写

```
（走过去把外套披在她肩上）今天风大，别着凉。
```

圆括号里的内容会被理解为**你的动作**，她看得见并会回应。

### 她也会写

```
<ja>（肩をびくっと跳ねさせて）……ありがとう、ございます。</ja>
<zh>（肩膀轻轻一颤）……谢谢。</zh>
```

### 三条规则

1. **只有文字回合允许**——通话里不给她这个说明，否则 TTS 会把「（脸红）」念出来
2. 语气提示仍然只用方括号 `[whisper]`，和圆括号各管各的
3. 朗读时会跳过圆括号里的动作（`delivery_cues.voiced()` 会剥掉）

## 三、群聊（本版最大的新增）

上游没有群聊。这里是一套**独立于单聊**的子系统：自己的表、自己的引擎路径、**不碰好感度**。

### 能做什么

| 能力 | 说明 |
|---|---|
| 建群 | 勾 2–4 个人；群名可改（点标题） |
| 和一群人说话 | 你发一句，**谁接由后台模型判断** |
| 她们互相接话 | 一个人说完，另一个可能补一句（最多 3 条回复） |
| 指定对谁说 | 输入框写 `/真乃 今天练习怎么样？`，只有她回 |
| 让她们自己聊 | 顶部开关，每 20 秒一轮，**关掉网页就停**，开满 20 分钟自动关 |
| 邀请新成员 | 群里点「邀请」，新人进群会插入系统消息并有欢迎对话 |
| 听她们说话 | 每条回复下有「朗读」，用她自己的音色合成（有缓存） |

### 谁接话怎么判断

后台模型读「在场有谁 + 最近 8 条 + 你这句」，输出 JSON 挑 1–2 人：

- 你点名谁，谁先
- 只有某人知道的事，只选她
- **上轮说过话的人往后排**（防止一个人抢话）
- 你说累/难过/要走，可能两个人一起关心
- 没人适合就不回

### 好感度：只读不写

- 群里说话**不改变任何人的好感分**
- 但她**会读到自己的档位**，所以爱意档的人在群里也更亲
- **别人看得出来**：如果制作人和某人比和你更亲近，你会读到一句提示，可以有反应（在意、起哄、装作没看见），但不会说出数值

### 界面

- 左侧对话列表顶部有「群聊」分组（叠头像 + 群名 + 最后一句）
- 群聊页：头像、名字、日文原文 + 中文字幕、逐条流式出现、带「某某正在输入……」

### 已知限制

- 没有剧情检索和长期记忆（只有最近若干条历史）
- 没有语音输入（打字或 `/名字`）
- 每次最多 3 条回复、最多 4 人
- 自动聊天靠页面驱动：**浏览器关掉就停**

## 四、接电话她先开口

单聊时点通话，她会先说一句欢迎的话，不用等你先出声。

- 接口：`POST /api/characters/{id}/call-opener/speech`
- 合成一次后缓存在 `/data/speech`，同一句不重复花钱
- 上游没有这个行为

---

## 五、主动搭话与浏览器通知

上游有 reach-outs 的基础，这里的调整：

- 每天最多 8 次（可配）
- 到点会推给浏览器通知（需要授权）
- 搭话间隔可调

## 六、显示调节（手机友好）

设置 → 外观：

| 旋钮 | 作用 |
|---|---|
| **界面比例**（90/100/110/120%） | 整站缩放，图片按钮一起变 |
| **字号**（90/100/110/125%） | 只放大文字 |

存在本机，打开页面自动应用。

---

## 七、这一版的取舍

- 群聊**刻意不做**：语音、照片、礼物、搭话、通话、记忆检索、加人踢人
- 好感度在群里**只读**，是为了避免「一句话四个人判定」的额外开销和互相干扰
- 自动聊天听页面指挥，是为了**关掉网页就不烧钱**

## 九、需要自备（仓库里没有）

| 东西 | 为什么没有 | 怎么补 |
|---|---|---|
| `.env` | 含密钥和个人地址 | 复制 `.env.example` 填自己的 |
| `corpus/` | 剧情库与立绘，约 2.8 GB，版权原因 | 自行导入 |
| `certs/` | TLS 证书和私钥 | 自己生成，见 `docs/deploy.md` |

`deploy/https-nginx.conf` 里 `YOUR-TAILNET-HOSTNAME.ts.net` 是占位符，换成你自己的域名。

---

## 十、合并上游时注意

`affinity.py`、`affinity_judge.py`、`engine.py`、`reply_format.py`、`app.py` 都动过，上游更新后这几处最容易冲突。群聊是独立文件，基本不会冲突。
